# NEXUS ARCADE

A web gaming hub with five fully playable browser games built in pure HTML, CSS, and JavaScript. No frameworks, no dependencies, no build tools — just one file.

## Games

- Snake — Classic grid-based snake. Eat, grow, don't crash.
- Memory Match — Flip cards and find all 8 matching pairs.
- Tic-Tac-Toe — 2-player or versus an unbeatable minimax AI.
- 2048 — Slide and merge tiles to reach the golden number.
- Reaction Timer — Test your reflexes. Click on green.

## Features

- Zero external dependencies
- Keyboard and touch/swipe support on all games
- In-session score and stat tracking
- Dark neon aesthetic built for late-night sessions
- Single self-contained HTML file

## Play

Open https://nexus-arcade-five.vercel.app/ in any modern browser — that's it.
